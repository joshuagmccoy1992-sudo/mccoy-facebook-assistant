# McCoy Carpentry — Free Lead Watch

Free scheduled public-search lead discovery for Cincinnati / Northern Kentucky. **No Facebook login, CAPTCHA bypass, group commenting, or automatic posting.** Results may include stale or unrelated pages; verify dates, location and group rules.

## iPhone use

Go to **Actions → Free Lead Watch → Run workflow** to start a manual run. The workflow also runs once a day (GitHub may delay scheduled runs). Open a completed run → **Artifacts → lead-results** to download a CSV.

## Notes

GitHub Actions usage is subject to GitHub's free allowances and account limits. Searches use public Bing RSS results, not private Facebook group data. The script doesn't collect contact information behind login.
